# the-moment-before

## Motor driver configuration:

SW1 SW2 SW3 SW4 SW5 SW6 SW7 SW8 
ON  ON  ON  ON  OFF ON  OFF ON

No microstepping

SW5 = OFF -> CCW
SW6 = ON  -> PM

Motor type 57

--

The code is written for Arduino Nano Every

## Onboard LED indications:
OFF -> homing
ON  -> running
SLOW blink -> in pause
FAST blink -> failed --> requires manual reset/
